# Criterios de entrada a Angular

## Decisión

Una persona está preparada para comenzar el proyecto Angular cuando puede completar y defender el capstone con autonomía razonable.

## Mínimos obligatorios

### Plataforma web

- estructura HTML semántica;
- formularios nativos y validación comprensible;
- layout responsive con CSS propio;
- navegación por teclado;
- uso correcto de enlace y botón.

### JavaScript

- scope y diferencia entre valor y referencia;
- funciones y módulos;
- arrays y objetos;
- transformaciones de datos;
- errores y `try/catch` con criterio;
- promesas y `async/await`;
- comprensión operativa del orden asíncrono.

### Navegador

- selección y creación de nodos;
- eventos y bubbling;
- lectura de formularios mediante `FormData`;
- URL y query params;
- storage con serialización defensiva;
- uso básico de DevTools.

### HTTP

- petición y respuesta;
- métodos y códigos habituales;
- JSON y `multipart/form-data`;
- loading, empty, error y success;
- CRUD básico;
- cancelación de una búsqueda o explicación correcta de por qué es necesaria.

### TypeScript

- tipos de dominio;
- uniones y narrowing;
- `unknown` para datos externos;
- genéricos básicos;
- utility types;
- ausencia de `any` como salida habitual.

## No requerido todavía

- arquitectura empresarial compleja;
- patrones avanzados de gestión global de estado;
- internals de motores JavaScript;
- optimización prematura;
- metaprogramación avanzada;
- conocimiento exhaustivo de Web Components.

## Formato de validación

1. Demostración funcional del capstone.
2. Revisión de un flujo feliz y dos casos de error.
3. Cambio pequeño realizado en directo.
4. Explicación de una decisión de HTML/CSS, una de asincronía y una de tipos.
5. Valoración con la rúbrica.

## Resultado

- **Preparado:** cumple mínimos y obtiene al menos 70/100.
- **Preparado con refuerzo:** cumple mínimos, pero necesita acompañamiento en uno o dos bloques.
- **Aún no preparado:** falla un mínimo esencial; se asignan ejercicios concretos, no el itinerario completo de nuevo.
