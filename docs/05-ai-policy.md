# Política de uso de IA

## Propósito

La IA puede acelerar aprendizaje y revisión, pero no debe reemplazar la comprensión que esta formación pretende medir.

## Uso permitido

- pedir explicaciones sobre un concepto;
- generar casos de prueba adicionales;
- revisar accesibilidad, nombres o estructura;
- comparar alternativas después de tener una primera solución;
- solicitar pistas acotadas;
- interpretar un error que la persona ya ha reproducido.

## Uso no válido como evidencia de competencia

- entregar código generado que la persona no puede explicar;
- pedir la solución completa del ejercicio y copiarla;
- ocultar el historial de decisiones cuando el mentor lo solicita;
- usar IA para responder la defensa oral en tiempo real;
- desactivar reglas o tipos para aceptar una respuesta generada.

## Regla práctica

Toda línea relevante de una entrega debe poder explicarse, modificarse y depurarse sin volver a pedir a la IA que regenere el archivo completo.

## Evidencias recomendadas

Cada entrega debería incluir en el Pull Request:

1. qué se implementó;
2. qué decisiones se tomaron;
3. qué ayuda externa se utilizó;
4. qué parte resultó más difícil;
5. cómo se comprobó el resultado.

## Evaluación con IA disponible

No es necesario prohibirla. Para verificar competencia:

- pide modificar un requisito durante la revisión;
- introduce un caso límite nuevo;
- pregunta por una alternativa;
- solicita localizar un fallo con DevTools;
- revisa primero el comportamiento y después el código.
